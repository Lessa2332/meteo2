## 📖 Про проєкт

**Метеощоденник** — це **повністю автономний вебзастосунок** для дітей 7–10 років, який перетворює щоденні спостереження за погодою на захопливу наукову гру. Застосунок працює **без серверів, без реєстрації, без реклами** — усе зберігається лише в браузері дитини.

### ✨ Ключові можливості

| 🎯 | Особливість |
|---|---|
| 📅 | **Календар погоди** з тепловою шкалою (від -25°C до +35°C) |
| 🌡️ | **Інтерактивний рідинний термометр** з анімацією |
| 🧭 | **Компас вітру та флюгер** — 8 напрямків |
| 👕 | **Порадник одягу** залежно від температури та неба |
| 🏆 | **Квести та бейджі** — геймифікація спостережень |
| 📊 | **SVG-графіки** температури + роза вітрів |
| 🛰️ | **Порівняння з супутником Open-Meteo** (реальні дані) |
| 🌍 | **6 мов**: українська, англійська, іспанська, німецька, польська, французька |
| 👥 | **Мультипрофіль** — кожна дитина має свій щоденник |
| 📲 | **PWA** — встановлюється на телефон як застосунок |
| 🔒 | **Працює офлайн** — 100% даних у localStorage |
| ♿ | **Доступність**: контраст, шрифт для дислексії, kid mode |
| 🖨️ | **Друк шкільного звіту** з таблицею спостережень |
| 💾 | **Експорт/імпорт** файлів `.weather` |
